# Paróquia São João Bosco

Projeto extensionista desenvolvido no curso de Análise e Desenvolvimento de Sistemas com o objetivo de criar uma plataforma digital responsiva para auxiliar na divulgação das atividades da Paróquia São João Bosco, localizada em São José dos Campos/SP.

---

## 📌 Objetivo do Projeto

O projeto foi desenvolvido com foco na modernização da comunicação paroquial, permitindo centralizar informações importantes da comunidade, como:

- Horários das missas
- Calendário litúrgico
- Eventos e avisos
- Catequese
- Contato da secretaria
- Redes sociais

A proposta está alinhada ao ODS 9 – Inovação e Infraestrutura, promovendo maior acesso às tecnologias de informação e comunicação.
